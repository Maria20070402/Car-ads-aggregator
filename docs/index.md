# Розробка вебплатформи для агрегації оголошень про продаж автомобілів

Кваліфікаційна робота на здобуття ступеня фахового молодшого бакалавра ([Закарпатський політехнічний фаховий коледж](https://zmt.com.ua/)).

Керівник роботи – **Бабич Олександр Вікторович**.

## Завдання до дипломної роботи
Розроблений продукт має являти собою вебплатформу для централізованої агрегації оголошень про продаж автомобілів з різних джерел. Він має забезпечувати можливість збору, обробки та уніфікації даних про транспортні засоби, їх характеристики та умови продажу, а також надавати користувачам інструменти для пошуку, фільтрації та порівняння пропозицій. Функціональність платформи має відповідати чинній нормативній базі України у сфері електронної комерції, захисту персональних даних та правил публікації оголошень. При розробці слід подбати про зручний інтерфейс для різних категорій користувачів (продавці, покупці, адміністратори), багатокористувацький доступ з механізмами авторизації та можливість роботи у вебсередовищі з доступом у реальному часі. Для реалізації проєкту доцільно використати сучасні програмні засоби веброзробки, реляційні бази даних для зберігання інформації та хмарні сервіси для адміністрування й масштабування.

* CSS
* JavaScript

Розроблену вебплатформу для агрегації оголошень про продаж автомобілів опубліковано та розгорнуто у мережі Інтернет. Доступ до системи здійснюється за посиланням: https://www.premiumauto.website/
